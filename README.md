# New-Blog-Site
# Blog Website

A full-stack Blog Website built using the MERN stack that allows users to create, manage, and explore blog posts with a clean and responsive user interface.

---

## 🚀 Features

- Create, edit, and delete blog posts
- Responsive design for all devices
- User authentication
- REST API integration
- Modern frontend using React + Vite
- Organized backend architecture
- MongoDB database integration

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
